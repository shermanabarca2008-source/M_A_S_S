Términos y Condiciones de M.A.S.S.

Última actualización: julio de 2026

1. Aceptación

Al crear una cuenta, el usuario confirma que ha leído y acepta estas condiciones para utilizar el sistema de agendamiento médico M.A.S.S.

2. Datos personales

El sistema registra los datos proporcionados en el formulario, como identificación, nombres, fecha de nacimiento, teléfono, correo y dirección, únicamente para identificar al paciente, gestionar su cuenta y administrar sus citas.

3. Privacidad y confidencialidad

La información médica y personal debe ser tratada de manera confidencial y utilizada solamente por personal autorizado para prestar los servicios disponibles en el sistema.

4. Responsabilidad del usuario

El usuario se compromete a ingresar información verdadera, mantener su contraseña protegida, no compartir su cuenta y actualizar sus datos cuando sea necesario.

5. Citas médicas

El usuario debe revisar la fecha, hora y médico antes de confirmar una cita. Si no puede asistir, deberá cancelarla o reagendarla oportunamente desde las opciones habilitadas.

6. Seguridad

M.A.S.S. aplica controles de acceso para proteger la información. El usuario debe cerrar sesión al utilizar equipos compartidos y comunicar cualquier acceso no autorizado.

7. Derechos del usuario

El usuario puede solicitar la revisión o corrección de sus datos personales mediante el personal responsable de la institución médica.

8. Uso del sistema

Está prohibido intentar acceder a cuentas ajenas, alterar información, afectar el funcionamiento del sistema o utilizarlo para actividades distintas a la gestión médica autorizada.
